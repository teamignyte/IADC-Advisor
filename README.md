# Appian Architect-in-a-Box — Workshop

The development workshop for the **Appian Architect-in-a-Box** bundle — a Claude Code configuration that turns Claude into an advisory Appian architect.

- **The deliverable** — what ships to a client — lives entirely under [`deliverable/`](deliverable/). Its own README is the user-facing guide.
- **Dev docs** for maintainers live here at the root: `CONTEXT.md` (bundle-design vocabulary), `docs/adr/` (decisions), and `for_liam.md` (maintainer orientation).
- **To try the bundle** as a client would, open Claude Code with `deliverable/` as the working directory and run `/setup`.

Only `deliverable/` is shipped; everything else here is the workshop. See [docs/adr/0001](docs/adr/0001-deliverable-lives-in-a-subfolder.md).
